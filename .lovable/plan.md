# نظام التسويق العقاري والمسوقين

## النتيجة
إضافة مركز متكامل داخل لوحة الإدارة لإدارة المسوقين، الروابط المخصصة، العملاء المنسوبين، الصفقات والعمولات، مع شرح مبسط داخل الصفحة. لا يتم إرسال أي رسالة واتساب تلقائيًا.

## ما سيتم بناؤه
- صفحة رئيسية للمسوقين تعرض مؤشرات الأداء: المسوقون النشطون، الزيارات، العملاء المحتملون، الصفقات، التحويلات، والعمولات المستحقة والمدفوعة.
- إضافة وتعديل ملف المسوق: الاسم، الجوال، البريد، المناطق والتخصص، طريقة العمولة، النسبة أو المبلغ، الحالة، والملاحظات.
- رابط إحالة فريد لكل مسوق مع نسخ الرابط، رمز QR، وتحديد مدة حفظ الإحالة.
- تسجيل زيارات روابط المسوقين بدون بيانات شخصية، ثم ربط الطلب أو الحجز بالمسوق عند تقديم العميل بياناته.
- صفحة تفاصيل لكل مسوق تشمل مسار التحويل من زيارة إلى طلب إلى صفقة، العملاء، العقارات المرسلة، العمولات، وسجل النشاط.
- إدارة العمولة بحالات واضحة: متوقعة، مستحقة، معتمدة، مدفوعة، ملغاة؛ ولا تُعتمد تلقائيًا بمجرد فتح الرابط.
- معالجة التعارض إذا جاء العميل من أكثر من مسوق وفق قاعدة إسناد قابلة للضبط، مع منع تكرار العميل بالجوال.
- إرسال عقار لمسوق أو مجموعة مختارة يدويًا فقط من داخل النظام، مع رابط المسوق الخاص بالعقار وتسجيل عملية الإرسال.
- قسم «كيف يعمل النظام؟» داخل صفحة المسوقين يشرح الرابط والإسناد والعمولة خطوة بخطوة.
- إضافة قسم التسويق العقاري إلى القائمة والصلاحيات، مع عناوين ووصف مشاركة مخصصين للصفحات الجديدة.

## التفاصيل التقنية
- إنشاء جداول منفصلة للمسوقين، الزيارات، الإسناد/العملاء المحتملين، مشاركات العقارات، والعمولات، مع الفهارس والقيود اللازمة.
- إضافة GRANT وRLS لكل جدول؛ التسجيل العام يقتصر على بيانات الإحالة الآمنة، والإدارة الكاملة للموظفين المصرح لهم.
- إنشاء دالة آمنة لتسجيل زيارة الرابط وتثبيت رمز الإحالة في المتصفح، وربطه بالطلبات العامة عند إنشائها.
- استخدام مكونات النظام الحالية وألوانه الدلالية، ودعم العربية RTL والكمبيوتر والهاتف.
- الحفاظ على قاعدة واتساب الحالية: لا إرسال عند إنشاء مسوق أو رابط أو مهمة أو عمولة؛ الإرسال فقط بعد ضغطة صريحة ولمستلمين محددين.

## التحقق
- اختبار إنشاء مسوق ونسخ رابطه، فتح الرابط كزائر، تقديم طلب، وظهور الإسناد الصحيح.
- اختبار عدم احتساب زيارة فقط كعمولة، ومنع تكرار العميل، وتغيير حالات العمولة يدويًا.
- اختبار أن الإرسال لا يحدث إلا بزر الإرسال، وفحص البناء والصفحات على الكمبيوتر والهاتف.
