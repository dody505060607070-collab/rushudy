# تطوير لوحة الإدارة والمالك والعقارات

## النتيجة المطلوبة
تنفيذ الحزمة كاملة في مسار واحد: لوحة معلومات أقرب للمرجع، متابعة دقيقة للموظفين للمدير العام فقط، تجربة خاصة للمالك، واستكمال إدارة صور ومواقع وتصنيفات العقارات وصفحة المالك.

## ما سيتم بناؤه

### 1. سجل الأنشطة وحضور الموظفين
- إنشاء جلسات استخدام تسجل دخول الموظف، آخر نشاط، وقت المغادرة التقريبي، مدة الجلسة، الصفحة الحالية، والجهاز بصورة مختصرة.
- تسجيل العمليات المهمة تلقائيًا: إضافة وتعديل وحذف واعتماد السجلات، إنجاز المهام، وتغيير الحالات، مع وصف مفهوم للتغيير.
- إعادة تصميم صفحة سجل الأنشطة للمدير العام فقط، مع ملخص لكل موظف، حالة متصل/غير متصل، مدة الاستخدام، وقت أول وآخر ظهور، فلترة بالتاريخ والموظف ونوع العملية، وخط زمني للتفاصيل.
- عدم تسجيل كلمات المرور أو محتوى حساس، وعدم إتاحة السجل للموظفين العاديين أو الملاك.

### 2. لوحة المعلومات
- إعادة تنظيم لوحة المعلومات على نمط المرجع: بطاقات الوصول والمغادرة والعناصر القائمة، إشغال الوحدات، حركة أسبوعية، حالة الوحدات، الحجوزات، والأنشطة الأخيرة.
- إبقاء مؤشرات العقود والتحصيل والمتأخرات والمهام الحالية، مع حالات تحميل وفراغ واضحة.
- تحديث البيانات مباشرة عند تغيّر السجلات ذات الصلة.

### 3. صلاحية المالك ولوحته
- إضافة دور `owner` في جدول الأدوار المنفصل، وربطه بحساب دخول وبسجل المالك دون تخزين الدور داخل الملف الشخصي.
- تطبيق سياسات وصول تجعل المالك يرى فقط عقاراته ومبانيه ووحداته وعقوده ومستأجريه ودفعاته وفواتيره، دون بيانات ملاك آخرين.
- توجيه المالك بعد الدخول إلى لوحة خاصة تعرض محفظته، الإشغال، المستأجرين، العقود، الدفعات القادمة والمتأخرة، مع منع أدوات الإدارة العامة عنه.
- إضافة إدارة ربط حساب المالك من شاشة المدير العام بدل منح أي صلاحيات من المتصفح.

### 4. الصور والموقع والتصنيفات
- استكمال إدارة صور العقار: رفع متعدد، ترتيب بالسحب، اختيار الغلاف، حذف، معاينة بالحجم الكامل، وضبط موضع/قص الصورة المعروض دون إتلاف الأصل.
- عرض صور العقار كاملة في معرض العميل مع التكبير والتنقل.
- إضافة خريطة صغيرة داخل نموذج العقار؛ النقر أو سحب العلامة يملأ الإحداثيات، مع استمرار دعم رابط خرائط جوجل.
- ربط العقار بمعرّفات نوع العقار والمدينة والحي مع إبقاء الحقول النصية القديمة للتوافق، وإضافة النوع/الحي سريعًا من النموذج لمن لديه صلاحية الإعدادات.

### 5. صفحة المالك والمباني والسحب
- عرض مباني المالك كبطاقات واضحة، بداخل كل مبنى وحداته وإشغالها والمستأجر والعقد والدفعات.
- إضافة منطقة للعقارات والوحدات غير المرتبطة.
- دعم سحب الوحدة أو العقار بين مباني المالك، وسحب العقد النشط إلى وحدة صالحة مع تحقق يمنع التعارض أو النقل إلى مالك آخر.
- الاحتفاظ ببيانات المالك والتصدير والتواصل والفواتير الحالية.

## الأمان والبيانات
- إضافة كل الجداول والحقول الجديدة عبر migration واحدة أو migrations مترابطة، مع `GRANT` صريح ثم RLS وسياسات لكل جدول جديد.
- تنفيذ العمليات الحساسة والنقل وربط حساب المالك عبر وظائف محمية تتحقق من هوية المستخدم وصلاحياته على الخادم.
- عدم تعديل مشروع مثراء أو جداول الشات المشتركة، وعدم حذف أي بيانات حالية.
- تسجيل التغييرات من قاعدة البيانات حيث أمكن لضمان عدم تجاوز سجل الأنشطة.

## التحقق
- تحديث أنواع قاعدة البيانات بعد التغييرات.
- اختبار صلاحيات المدير والموظف والمالك، ومنع الوصول المتبادل.
- اختبار الصور والسحب والخريطة على الهاتف والكمبيوتر.
- اختبار لوحة المعلومات وصفحة النشاط وصفحة المالك بصريًا، ثم مراجعة سجل البناء والتشغيل.
